# 🎬 Aplicación Web de Gestión de Películas y Series

Proyecto desarrollados con arquitectura desacoplada (Full-Stack).

## 🚀 Tecnologías Utilizadas
* **Frontend:** React.js, Vite, Axios, Bootstrap
* **Backend:** Node.js, Express, Mongoose
* **Base de Datos:** MongoDB Atlas (NoSQL)
* **Despliegue:** Netlify (Frontend) & Render (Backend)

## 🌐 Enlaces Públicos
* **Frontend:** [Ver App en Netlify](https://cineflixv1.netlify.app/media)
* **Backend API:** [Ver API en Render](https://api-peliculas-dfhd.onrender.com)

## 🛠️ Instalación Local
1. Clonar el repositorio: `git clone <URL_DEL_REPO>`
2. Instalar dependencias: `npm install`
3. Ejecutar en desarrollo: `npm run dev`
